# 🤖 LangChain Groq Q&A Chatbot

A beginner-friendly Generative AI Q&A chatbot built using LangChain, Groq LLMs, and Streamlit.

## 🚀 Features

- Interactive Q&A chatbot
- Powered by Groq LLMs
- Built using LangChain
- Streamlit-based web interface
- Chat history maintained during the session
- Model selection through the sidebar
- Secure API key input

## 🛠️ Tech Stack

- Python
- LangChain
- Groq
- Streamlit
- LangGraph
- Python-dotenv
